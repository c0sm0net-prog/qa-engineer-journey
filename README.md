# 🚀 QA Portfolio & Learning Journey
Мое портфолио, QA-тестирование. Артефакты тестирования, SQL, API.

## 🛠 Навыки и инструменты
- **Теория тестирования:** Понимание жизненного цикла ПО, видов и уровней тестирования.
- **Тестовая документация:** Написание тест-кейсов, чек-листов, баг-репортов.
- **Техники тест-дизайна:** Классы эквивалентности, граничные значения, pairwise.
- **Web & DevTools:** Понимание клиент-серверной архитектуры, анализ сетевых запросов.
- **API Testing:** Тестирование REST API с помощью Postman (GET, POST, PUT, DELETE).
- **SQL:** Написание базовых запросов (SELECT, JOIN, GROUP BY).
